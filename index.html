이동·공격

  • Z × 3잽(Jab) 가장 빠르고 약한 3단 기본기. 근거리 탈출·피해 누적용
  • 방향 → Z 탭강공격(Tilt) Z를 짧게 놓으면 발동. 잽보다 강하고 길며, 스매시보다 빠르고 빈틈이 적음
  • ↗/↘ + Z공격 각도 조절 옆 틸트·스매시의 타점과 발사 각도를 위아래로 변경
  • Z 길게 홀드스매시 공격 14프레임부터 충전. 방향 없이 모으면 앞 스매시이며, 홀드 중 방향으로 위·아래·앞 선택
  • 대시 중 Z대시 공격 전진 판정이 길지만 막히거나 빗나가면 반격에 취약
  • 공중 ZNAir 빠르고 오래 남는 전신 판정. 근접 견제·탈출용
  • 공중 앞 + ZFAir 전방 범위가 넓은 콤보 시작·연계용
  • 공중 뒤 + ZBAir 바라보는 반대쪽을 치는 강한 마무리기
  • 공중 위 + ZUAir 위의 상대를 띄워 연속 추격하는 대공기
  • 공중 아래 + ZDAir 아래로 내려찍는 메테오. 강하지만 발동·착지 빈틈이 큼
  • XNeutral Special 캐릭터의 대표 필살기
  • ←/→ + XSide Special 좌우 방향 필살기
  • ↑ + XUp Special 공중에서 한 번만 쓰는 주 복귀기. 착지·절벽 잡기로 회복
  • ↓ + XDown Special 카운터·설치·범위 제어 등 캐릭터 고유 기술
  • 반대 방향 → XB리버스 반대 방향을 빠르게 튕긴 직후 중립 필살기로 관성과 방향 반전
  • X → 반대 방향턴어라운드 필살기 발동 직후 4프레임 안에 방향만 반전
  • Z + X최종 필살기 게이지 100%일 때 발동. 기존 조작 유지
  • ↑ 짧게숏홉 점프키를 빨리 놓아 낮게 점프
  • 방향키 유지걷기·달리기 처음에는 걷고 계속 유지하면 달리기, 빠르게 두 번 입력하면 대시
  • Ctrl + 방향키정밀 이동 달리기로 전환하지 않고 느린 걷기를 유지
  • BOLT ↘/↙기어가기 낮은 자세를 유지하며 천천히 전진
  • 하강 중 ↓급강하 정점을 지난 뒤 새로 입력하면 빠르게 낙하하며 반짝임 표시
  • 지상 ↓앉기 내성 앉은 상태로 피격되면 넉백이 85%로 감소
  • 반대 방향급정지 대시 중 반대로 꺾어 제동·방향 전환

방어·회피

  • C 유지실드 내구도 50. 공격을 막을수록 작아지고 0이면 실드 브레이크
  • C 유지 → 피격 직전 해제패링 실드를 잠깐 유지한 뒤 놓은 직후 5프레임에 공격을 받아 공격자를 정지
  • C + X 유지 + 방향실드 시프트 실드 중심을 옮겨 노출된 신체를 보호
  • C 중 ↑ + Z / X실드 캔슬 위 스매시 또는 위 필살기로 바로 반격
  • ←/→ + C구르기 이동하며 상대를 통과하는 지상 회피
  • ↓ + C제자리 회피 막판에는 Z/X로 바로 반격 가능
  • 공중 C공중 회피 중립은 관성 유지, 방향 입력 시 방향 회피
  • 착지 직전 C낙법 튕겨 날아갈 때 착지 직전 입력
  • 착지 전 방향+C구르기 낙법 입력 방향으로 낙법하며 이동

공중 회피는 한 번만 가능하며 착지·절벽 잡기 후 회복됩니다. 회피를 연속 사용하면 무적은 짧아지고 후딜은 늘어납니다.

피격 상태

  • 타격 순간히트랙 공격자와 피격자가 함께 잠깐 정지해 타격을 확인
  • 히트스턴 중행동 불가 넉백 방향 조절과 히트랙 중 SDI만 가능
  • 히트스턴 종료자유낙하 공중 점프·공중기·공중 회피로 탈출 가능. 행동 전에는 급강하 불가
  • 위 X 종료무방비 어두워진 채 약한 방향 조절과 급강하만 가능. BOLT 스프링은 예외
  • 무방비 중 피격복귀기 회복 공중 점프는 소모된 채 위 필살기를 다시 사용할 수 있음
  • 하얀 점멸무적 타격·잡기·아머 파괴를 포함한 모든 공격을 무시

BLAZE의 브레이커 러시는 9 이하 피해만 버티는 헤비아머입니다. 슈퍼아머는 피해량과 관계없이 경직·넉백을 무시하지만 피해 자체는 받습니다.

잡기·기상

  • V잡기 실드 중 V 또는 Z로도 잡기 가능
  • 대시 중 V대시 잡기 발동은 느리지만 전진 거리와 잡기 범위가 증가
  • 잡은 뒤 Z/V잡기 타격 짧게 때려 피해를 누적. 욕심내면 상대가 탈출
  • 잡은 뒤 앞앞 던지기 가장 약하지만 상대를 절벽 쪽으로 밀어냄
  • 잡은 뒤 뒤뒤 던지기 가장 강한 넉백을 가진 마무리용 던지기
  • 잡은 뒤 위위 던지기 상대를 띄워 공중 추격을 시작
  • 잡은 뒤 아래아래 던지기 낮게 띄워 지상·공중 콤보로 연계
  • 잡혔을 때 연타잡기 탈출 방향키와 Z/X/V/C를 빠르게 입력
  • 다운 중 ←/→기상 구르기 입력 방향으로 무적 이동
  • 다운 중 Z기상 공격 공격하며 일어나기
  • 다운 중 ↑/C제자리 기상 짧은 무적과 함께 일어나기
  • 실드 브레이크 중 연타매시 방향·공격 버튼을 빠르게 바꿔 기절 시간을 단축

절벽·복귀

  • 절벽 ↑절벽 점프 위로 뛰어 복귀
  • 절벽 Z/X절벽 공격 올라오며 공격
  • 절벽 C/V절벽 구르기 전반부 무적으로 안쪽까지 이동
  • 절벽 안쪽빠른 올라오기 가장 짧은 빈틈으로 지상 복귀
  • 절벽 바깥쪽/↓절벽 놓기 바깥쪽은 놓기, 아래는 급강하하며 놓기
  • 날아갈 때 방향DI·공중 제어 날아가는 각도와 감속 방향을 조절
  • 상대 머리 위에서 ↑풋스툴 상대를 밟아 튕기며 공중 점프를 보존
  • 상대가 잡은 절벽 잡기절벽 트럼프 먼저 매달린 상대를 밀어내고 절벽 차지
  • 피격 정지 중 방향SDI 강한 타격의 정지 순간에 위치를 미세 조절

아이템이 없는 1대1은 피해량이 1.2배이며, 화면 밖에서 낙사선 안에 오래 머물면 초당 1% 피해를 받습니다. 상단 KO는 일정 확률로 별·스크린 KO가 발생해 재등장이 늦어집니다. 리스폰 발판에서는 최대 2초간 무적이며, 기다린 시간만큼 남은 무적 시간이 줄어듭니다.
