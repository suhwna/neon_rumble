# NEON RUMBLE ONLINE

NEON RUMBLE은 최대 4명이 브라우저에서 함께 플레이하는 서버 권한형 플랫폼 난투 게임입니다. 누적 피해율이 높을수록 더 멀리 날아가며, 상대를 스테이지의 낙사선 밖으로 보내 목숨을 모두 소진시키면 승리합니다.

현재 버전은 `1.1.0-beta.4`입니다.

## 주요 기능

- 60Hz 고정 틱 서버 권한형 전투
- 2~4인 온라인 친구방과 공개 매칭
- 방 목록, 대기방 자유 대련, 캐릭터 선택과 준비 상태 표시
- 목숨전, 시간전, 2대2 팀전
- 연습 모드, 기본 튜토리얼, 입력 기록, 판정 표시, 프레임 정지
- Dummy, Easy, Normal, Hard CPU
- 누적 피해, 히트스톱, 히트스턴, 넉백, DI/SDI, 콤보 보정
- 실드, 얼티밋식 패링, 구르기, 제자리 회피, 공중 회피, 낙법
- 잡기, 잡기 공격, 4방향 던지기, 재잡기 방지
- 절벽 잡기와 다섯 가지 절벽 선택지
- 익명 전적 저장, 재접속, 핑 표시, 입력 검증
- 게임 내 패치 노트와 `/healthz` 운영 상태 확인

아이템과 관전 기능은 현재 사용자 인터페이스에서 비활성화되어 있습니다.

## 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm start
```

브라우저에서 [http://localhost:4173](http://localhost:4173)을 엽니다. 같은 네트워크의 다른 기기는 `http://서버-PC-IP:4173`으로 접속할 수 있습니다.

4173 포트가 이미 사용 중이라면 기존 서버를 종료하거나 다른 포트를 지정합니다.

```powershell
$env:PORT = "4180"
npm start
```

## Docker

## 게임 시작

### 공개 매칭

메인 화면에서 공개 매칭을 선택합니다. 4명을 우선 모집하고, 대기 시간이 지나면 2명 이상으로 경기를 시작합니다. 기본 규칙은 3목숨, 7분, 아이템·기믹 끔입니다.

### 친구방

메인 화면의 방 목록에서 입장하거나 새 방을 만듭니다. 대기방에서는 자유 대련을 하면서 캐릭터와 팔레트를 고르고 준비할 수 있습니다. 방장은 모드, 목숨, 제한 시간, 팀, 스테이지와 기믹을 설정합니다.

### 연습 모드

메인 화면에서 연습 모드에 바로 입장할 수 있습니다. 기본 상대는 움직이지 않는 Dummy입니다. 연습 도구에서 다음 기능을 사용할 수 있습니다.

- 플레이어와 BOT 캐릭터 변경
- 위치·피해율·필살기 게이지 초기화
- Dummy/Easy/Normal/Hard CPU 선택
- 프레임 정지
- 공격·피격·투사체 판정 표시
- 단계별 기본 튜토리얼
- 전체 조작·기술 설명
- 격투 게임식 입력 기록

처음 플레이하는 브라우저에서는 기본 튜토리얼이 자동으로 시작됩니다.

## 조작

| 입력 | 기능 |
| --- | --- |
| `←/→` 또는 `A/D` | 걷기, 달리기, 두 번 입력 시 대시 |
| `↑`, `W`, `Space` | 점프, 공중에서 한 번 더 입력해 2단 점프 |
| `↓` 또는 `S` | 앉기, 공중 하강 중 빠른 낙하, 반투명 발판 통과 |
| `Z` 짧게 | 지상 잽 / 공중 중립 공격 |
| `방향 + Z` 짧게 | 방향 틸트 / 방향 공중 공격 |
| `Z` 14프레임 이상 홀드 | 스매시 차지. 방향 없이 모으면 앞 스매시 |
| `X` | 중립 필살기 |
| `방향 + X` | 옆·위·아래 필살기 |
| `C` | 지상 실드 / 공중 회피 |
| `방향 + C` | 좌우 구르기, 아래 제자리 회피, 방향 공중 회피 |
| `V` | 지상 잡기 / 공중 회피 |
| 잡은 상태에서 `Z` 또는 `V` | 잡기 공격 |
| 잡은 상태에서 방향 | 앞·뒤·위·아래 던지기 |
| `Z + X` | 게이지가 가득 찼을 때 지상 궁극기 |

보조 키로 `F=Z`, `G=X`, `Shift=C`, `E=V`도 지원합니다.

### 스매시 입력

지상에서 Z를 놓으면 잽 또는 틸트가 즉시 발동합니다. Z를 약 14프레임 이상 확실하게 누른 경우에만 스매시 차지로 전환됩니다. 차지 중 방향을 입력해 앞·위·아래 스매시를 선택할 수 있고, 최대 1.4배까지 강화됩니다.

### NOVA 워프 차지

NOVA의 옆 X와 위 X는 X를 누른 시간에 따라 순간이동 거리가 증가합니다.

- 블링크 슬래시: 약 72~230 거리
- 워프 라이즈: 세로 약 120~184, 대각선 가로 약 150~255
- 최대 60프레임에서 자동 발동

## 캐릭터

| 캐릭터 | 역할 | 대표 필살기 |
| --- | --- | --- |
| VOLT | 빠른 러시다운 | 전기 투사체, 돌진, 상승 복귀, 근거리 방전 |
| BLAZE | 중량급 파워 | 차지 포격, 헤비아머 돌진, 로켓 복귀, 카운터 |
| BOLT | 트릭과 지형 제어 | 왕복 부메랑, 구르기 공격, 스프링 복귀, 지면 충격파 |
| NOVA | 공중 기동과 워프 | 별 투사체, 차지 워프 베기, 차지 워프 복귀, 중력장 |

각 캐릭터는 잽 3연타, 방향별 지상 공격, 다섯 가지 공중 공격, 네 가지 필살기와 고유 궁극기를 가집니다.

## 스테이지

- Neon Deck: 막힌 주 지면과 좌우 반투명 발판
- Sky Rail: 이동 발판과 선택형 바람 기믹
- Reactor Core: 분할 지형과 선택형 에너지 펄스

## 온라인 구조

- Socket.IO 입력 메시지: 순번, 클라이언트 시간, 버튼 비트, 수평·수직 축
- 서버 스냅샷: 틱, 서버 시간, 입력 ACK, 규칙, 스테이지, 플레이어와 엔티티
- 로컬 예측과 서버 재조정
- 60~140ms 적응형 보간 버퍼
- RTT 중앙값 기반 핑과 연결 품질
- 30초 재접속 슬롯 보존
- 초당 60개 입력 제한과 순번·축 값 검증
- 방장 이탈 시 설정 권한 자동 승계

## 환경 변수

| 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | `4173` | HTTP와 Socket.IO 서버 포트 |
| `NEON_DB_PATH` | 런타임 기본 경로 | SQLite 데이터베이스 경로 |
| `NEON_SECRET` | 자동 생성·보존 | 익명 사용자와 재접속 토큰 서명 키 |
| `NEON_RECONNECT_MS` | `30000` | 연결 종료 후 슬롯 보존 시간 |
| `NEON_QUEUE_WAIT_MS` | `20000` | 공개 매칭이 2명 이상으로 시작하기까지의 대기 시간 |

## 운영 확인

- `GET /healthz`: 버전, 가동 시간, 방·플레이어·대기열 수, 틱 비용
- `GET /releases.json`: 현재 버전과 게임 내 패치 노트
