# NEON RUMBLE ONLINE

서버 권한형 2–4인 웹 플랫폼 난투 게임입니다. 독자적인 네온 벡터 캐릭터 4종과 스테이지 3종을 사용하며, 친구방·공개 매칭·연습 모드를 지원합니다.

## 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm start
```

브라우저에서 `http://localhost:4173`을 엽니다. 같은 네트워크에서는 `http://내-PC-IP:4173`으로 접속할 수 있습니다. 인터넷 대전은 이 Node.js 앱을 외부 서버에 배포해야 합니다.

## 조작

| 기능 | 키보드 | 게임패드 |
| --- | --- | --- |
| 이동·점프·빠른 낙하 | WASD 또는 방향키 | 스틱 / A |
| 방향 공격·차지 | F + 방향, F 홀드 | X + 스틱 |
| 방향 필살기 | G + 방향 | B + 스틱 |
| 잡기·방향 던지기 | E + 방향 | Y + 스틱 |
| 방어·패링·공중 회피 | Shift | LB/RB |

선택된 캐릭터 카드를 다시 누르면 팔레트가 바뀝니다.
메인 화면의 **혼자 연습**을 누르면 방 설정 없이 Dummy CPU와 즉시 연습을 시작합니다. 연습 도구에서 Easy/Normal/Hard로 바꾸면 AI가 행동합니다.

## 포함된 기능

- 60Hz 고정 틱 전투 상태 머신과 기술별 선딜·활성·후딜·착지 프레임
- 6프레임 입력 버퍼·코요테 타임과 서버 응답 전 로컬 공격 포즈 표시
- 히트스톱, 차지 공격, 패링, 방어막, 잡기와 4방향 던지기, 공중 회피, 콤보 보정
- 대시·급정지·빠른 낙하·반투명 발판·절벽 잡기와 다섯 가지 절벽 행동
- VOLT, BLAZE, BOLT, NOVA의 지상기 4개·공중기 4개·필살기 4개
- Neon Deck, Sky Rail, Reactor Core와 선택 가능한 스테이지 기믹
- 목숨전·시간전·2대2 팀전·서든데스·연습 CPU 네 단계
- 4인 우선 공개 매칭, 20초 뒤 2인 이상 시작
- 입력 순번 검증, 60Hz 속도 제한, 30초 재접속, 서버 독립 경기 진행과 방장 승계
- RTT 중앙값 핑, 60–140ms 적응형 보간, 로컬 예측과 서버 위치 재조정
- 방향별 스쿼시·스트레치, 팔다리 모션, 공격 궤적과 기술명 표시
- 플레이어 간격을 추적하는 동적 전투 카메라와 화면 흔들림·줌 펀치·피격 플래시
- 스테이지별 원근 배경, 네온 발판 구조물, 캐릭터별 HUD와 화면 밖 위치 표시기
- 짧은 점프·높은 점프, 피격 방향 보정, 단계별 공격 감속과 실제 활성 프레임 발동
- Node 내장 SQLite 익명 전적과 `/healthz` 운영 상태

## 테스트

```bash
npm test
```

테스트는 전투 프레임, 히트스톱, 패링, 차지, 잡기·던지기, 콤보 보정, 절벽, 모드 점수, 팀 피해, SQLite, 4인 소켓 경기, 재접속, 방장 승계, 공개 매칭, 입력 검증 및 25개 동시 방 틱 예산을 검증합니다.

환경 변수:

- `PORT`: 서버 포트, 기본값 `4173`
- `NEON_DB_PATH`: SQLite 파일 경로
- `NEON_SECRET`: 익명 사용자·재접속 토큰 서명 키. 미설정 시 `.neon-secret`에 자동 보존
- `NEON_RECONNECT_MS`: 연결 종료 후 슬롯을 보존하는 시간, 기본값 `30000`

이 프로젝트는 장르의 핵심 규칙만 참고한 독자 게임이며 닌텐도의 캐릭터·상표·그래픽 자산을 포함하지 않습니다.
